# PRODiGY_GA_03 – Text Generation with Markov Chain

## Overview
This project demonstrates text generation using the Markov Chain algorithm. The model learns word patterns from a sample dataset and generates new sentences by predicting the next probable word based on statistical transitions. This project provides a practical introduction to probabilistic language models and Natural Language Processing (NLP).

## Objective
- Understand the concept of Markov Chains.
- Generate meaningful text using probabilistic language modeling.
- Learn the basics of Natural Language Processing (NLP).
- Build a simple text generation model using Python.

## Technologies Used
- Python
- Google Colab
- Markovify
- Jupyter Notebook
- GitHub

## Project Workflow
1. Install the required library (Markovify).
2. Import the necessary Python modules.
3. Create a sample text dataset.
4. Train the Markov Chain model.
5. Generate new text sentences.
6. Display and evaluate the generated output.

## Results
The Markov Chain model successfully generated readable text based on the provided dataset. The generated sentences demonstrate how probabilistic language models can produce meaningful text by learning word relationships.
